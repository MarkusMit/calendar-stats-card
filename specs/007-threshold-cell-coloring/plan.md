# Implementation Plan: Threshold-Based Cell Coloring

**Branch**: `007-threshold-cell-coloring` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)

## Summary

Adds threshold-based per-cell color overrides to the tabularizer card. Each data cell is independently evaluated against a list of `ThresholdRule` entries on its entity config; when multiple rules match, the closest threshold value wins. Named threshold rules render a combined card-level legend. Config is additive: new `thresholds` list on `EntityRowConfig`/`ExpressionRowConfig`; `text_color`/`background_color` field names are reused on each rule (no schema migration, no breaking change).

## Implementation Design

### 1. New Types in card-config.ts

```typescript
export type ThresholdOperator =
  | 'above' | 'equals-above' | 'equals-below' | 'below'
  | 'not-below' | 'not-above';

export type CellRole =
  | 'min' | 'avg' | 'max' | 'scalar'
  | 'summary-min' | 'summary-avg' | 'summary-max' | 'summary-scalar';

export interface ThresholdRule {
  operator: ThresholdOperator;
  value: number;
  name?: string;
  text_color?: string;
  background_color?: string;
}
```

Add `thresholds?: ThresholdRule[]` to both `EntityRowConfig` and `ExpressionRowConfig`. All other fields unchanged.

### 2. Threshold Resolver Service

**File**: `frontend/src/services/threshold-resolver.ts`

**`resolveThreshold(cellValue, thresholds, cellRole)`**:
1. Filter: exclude rules with no color fields (`!t.text_color && !t.background_color`).
2. Filter by role: `not-below` excluded for `'avg'`, `'max'`, `'summary-avg'`, `'summary-max'`; `not-above` excluded for `'min'`, `'avg'`, `'summary-min'`, `'summary-avg'`.
3. Evaluate operator against `cellValue`.
4. Select minimum `|cellValue - t.value|`; primary tie-break: higher `t.value` wins; secondary tie-break (same distance AND same `t.value`): first-defined rule (config definition order) wins.
5. Return winner or `undefined`.

**`buildCellStyle(staticTextColor, staticBgColor, threshold)`**:
- Start from static colors; override with threshold colors where threshold fields are defined.
- Return CSS style string or `undefined`.

### 3. Rendering Changes (year-table.ts and monthly-table.ts)

**Current**: one `labelStyle` per entity, applied uniformly to every cell (label, data, pad, summary).

**New split**:
- `staticStyle` = `buildCellStyle(cfg.text_color, cfg.background_color, undefined)` — unchanged for label, sub-label, and pad cells (no numeric value to evaluate).
- Per data cell: `buildCellStyle(cfg.text_color, cfg.background_color, resolveThreshold(cellValue, cfg.thresholds ?? [], cellRole))`.

**Cell role assignment**:

| Cell position | Role |
|---|---|
| Measurement min daily | `'min'` |
| Measurement avg daily | `'avg'` |
| Measurement max daily | `'max'` |
| Cumulative/expression daily | `'scalar'` |
| Measurement summary min | `'summary-min'` |
| Measurement summary avg | `'summary-avg'` |
| Measurement summary max | `'summary-max'` |
| Cumulative summary | `'summary-scalar'` |

Cells with no data value (missing, empty, pad beyond month end): use `staticStyle` — no threshold evaluation.

### 4. Legend Rendering (tabularizer-card.ts)

**Triggered-thresholds architecture**: year-table and monthly-table each accumulate every non-`undefined` `ThresholdRule` returned by `resolveThreshold` during their render pass (object-identity deduplication, first-seen order). After rendering, each dispatches a `thresholds-applied` CustomEvent (`bubbles: true, composed: true`) with `detail: { rules: ThresholdRule[] }`. `tabularizer-card` listens on its shadow root and stores the result in `@state() private _triggeredThresholds: ThresholdRule[] = []`, which triggers legend re-render.

Add legend collection and render after `<year-table>` inside `<ha-card>`:

```typescript
private _buildLegend(triggeredRules: ThresholdRule[]): Array<{name: string; text_color?: string; background_color?: string}> {
  const seen = new Set<string>();
  const entries = [];
  for (const rule of triggeredRules) {
    if (!rule.name || (!rule.text_color && !rule.background_color)) continue;
    if (seen.has(rule.name)) continue;
    seen.add(rule.name);
    entries.push({ name: rule.name, text_color: rule.text_color, background_color: rule.background_color });
  }
  return entries;
}
```

Legend CSS in `tabularizer-card.ts` static styles:
```css
.threshold-legend {
  display: flex; flex-wrap: wrap; align-items: center;
  gap: 4px 12px; padding: 4px 0 2px; font-size: 0.8em;
}
.legend-title { font-weight: bold; margin-right: 2px; }
.legend-entry { display: inline-flex; align-items: center; gap: 3px; }
.legend-swatch {
  display: inline-block; width: 12px; height: 12px; flex-shrink: 0;

}
```

Legend entry rendering:
- `background_color` present → `<span class="legend-swatch" style="background-color:...">` + name label (in `text_color` if set)
- `background_color` absent, `text_color` present → name label in `text_color` only (no swatch)
