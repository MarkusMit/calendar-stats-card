# Implementation Plan: Replace Hardcoded Precipitation Zero-Exclusion With `show_zero`

**Branch**: `010-precip-show-zero` | **Date**: 2026-05-30 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/010-precip-show-zero/spec.md`

## Summary

Remove the `device_class === 'precipitation'` branch in the monthly-summary computation pipeline and drive zero-day exclusion entirely from each row's existing `show_zero` config field.
Today `show_zero` only blanks day cells; after this change it also controls whether zero-value days enter the monthly summary min/avg/max for cumulative entity rows and expression rows.
The monthly **total**, `measurement` entities, and day-cell rendering are unchanged.
Editor toggle label is reworded ("Include zero-value days") and docs (README, constitution, CLAUDE.md, historic spec FR-016) are realigned.
